# User Testing Kit

## Protocol
Invite 5 participants (friends, family, or classmates) to test the EcoSort AI prototype. 
Do not guide them on how to use the UI. Just provide the task.

**Task for Participant:**
> “Use EcoSort AI to determine how the provided waste item (e.g., a battery or a pizza box) should be handled.”
